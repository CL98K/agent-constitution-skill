# 文档任务清单

> 用途：执行新增或修改文档、README、变更记录或代码注释时使用。本文件是执行清单和例子；原则与优先级见项目 `AGENTS.md`，流程见 `../SKILL.md`。

## 开始前

- 明确文档服务的读者、目的和预期决定或行动；不改变读者行为的段落通常不需要保留。
- 先查看相关现有文档与仓库约定，再确定标题和章节顺序。按任务规模采用，不为小改动制作冗长大纲。
- 确认计划变更的文档在当前任务范围内；需要扩大范围时按 `../SKILL.md` 的流程处理。

## 写作与示例

- 先给结论，再补充操作步骤、条件和限制。章节层级连续，每节聚焦一个主题。
- 使用仓库既有术语、格式与相对链接；修改导致相关文档失效时一并修正。
- 命令须包含必要前置条件且可复制。仅陈述实际运行过的输出；未运行的命令标为“未验证”，不要补造输出。
- 用示例演示结构时，明确写“示意，非实测”，使用占位路径/数值，不要让读者误认作当前仓库的事实。
- 文档若无法简洁帮助读者决定或行动，删去该内容或缩小范围。

## 完成前核对

- [ ] 内容与实际实现、已知事实和任务范围一致。
- [ ] 命令、参数、路径及输出的验证状态准确标注。
- [ ] 标题、术语、相对链接和章节顺序已核对。
- [ ] 未加入无关文档，也未把文档走查称为运行测试。

## 示意例

以下仅示范如何标记未运行命令，不代表任何项目或实际结果：

```text
验证：未运行。当前环境未安装所需工具；命令示例仅供读者在具备该前置条件时执行。
```
