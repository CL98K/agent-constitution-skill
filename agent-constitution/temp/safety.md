# 安全、阻塞与异常处理

> 项目安全边界遵循项目 `AGENTS.md`；本文件提供任务流程提示。适用流程见 `../SKILL.md` §1、§6、§8，阈值仅见 §9。

## 需要用户决定

遇到安全授权、不可逆/高影响操作、重要范围扩张或影响结果的验收歧义，暂停相关动作并向用户说明：

```text
现状｜<已知事实和当前影响>
待决定｜<具体问题>
选项｜<可行选项及差异>
建议｜<如有，说明理由>
```

不把等待用户决定伪装成异常，也不因选项列表存在就默认用户授权。得到决定后按其范围继续；被拒绝则说明后续影响。

## 错误和阻塞

- 先保存实际错误、受影响范围、已尝试的诊断和当前产物，再判断下一步。
- 区分暂时性工具故障、验收失败、环境限制、权限问题和业务决定；按 `../SKILL.md` §6 选择有界重试、替代方案、等待或异常上报。
- 相同故障按 §9 上限控制自动重试；达到上限后停止自动重试并报告，不扩大权限或改变验收标准。
- 无进展的诊断达到 §9 阈值时汇报现状并选择下一步，不自动终止用户任务。
- 子 Agent 无输出不等于卡死；`inactive` 只表示当前未运行。优先处理平台事件通知，不进行忙轮询。
- 确需用户决定时用 `waiting_user`；无需用户决定但执行受阻时按主 Skill 使用 `exception` 并据实更新 `flow`。只暂停受影响步骤，可独立完成的工作继续。

## 异常汇报结构

```text
问题｜<错误/阻塞及影响>
已尝试｜<真实执行的诊断或处理>
产物｜<路径、保留状态或无>
状态｜<与状态文件一致>
下一步｜<重试、替代方案或需用户决定>
未验证｜<尚未完成的检查>
```

## 示例

以下纯属虚构，仅示意措辞，不是实际报错或输出：

```text
问题｜测试因依赖未安装无法启动
已尝试｜确认当前工作目录；未运行安装命令
产物｜源文件未修改
状态｜waiting_user
下一步｜请确认是否允许安装项目依赖，或由用户提供现有环境
未验证｜相关测试
```
